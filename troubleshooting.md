# Markdown Quick Guide

A short reference for writing in Markdown.

## Headings
Use `#` for headings. More symbols make a smaller heading.

# Heading 1
## Heading 2
### Heading 3

## Text formatting
- **Bold:** `**bold text**`
- *Italic:* `*italic text*`
- ~~Strikethrough:~~ `~~text~~`

## Lists
Bulleted list:

- First item
- Second item

Numbered list:

1. Step one
2. Step two

## Links and images
- Link: `[Link text](https://example.com)`
- Image: `![Describe the image](image.png)`

## Code
Use single backticks for `inline code`. For a block, use three backticks on their own lines.

## Quotes and tables
> This is a quote.
