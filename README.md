# Hi, I'm Catherine

**Technical writer | French–English translator | Proofreader**

I turn software and no-code tools into clear, step-by-step guides that first-time users can follow. I come from a chemical engineering background, so I'm comfortable with technical and process-based topics, and I also work in French.

## What I write

- User guides and how-to tutorials
- Help center and knowledge base articles
- Onboarding guides for SaaS and no-code products
- French–English translation and proofreading

## How I work

1. **Learn the product as a new user.** Where I get stuck is where readers will too.
2. **Write one action per step**, starting each step with a verb.
3. **Test the steps** by following them exactly as written.
4. **Check accuracy:** facts, links, and terminology.
